# Streamlit Cloud Deployment Guide

## Quick Deploy (5 minutes)

### Step 1: Push to GitHub

```bash
cd C:\Users\Shivani\aegisstore
git add .
git commit -m "AegisStore Phase 1-5: Production ready with storage intelligence"
git push origin main
```

### Step 2: Go to Streamlit Cloud

1. Visit: https://share.streamlit.io
2. Sign in with your GitHub account (or create one)
3. Click **"Create app"**

### Step 3: Configure Deployment

- **Repository:** Select your aegisstore repo
- **Branch:** main
- **Main file path:** `dashboard.py`
- **App URL:** Create custom name (e.g., `aegisstore`)

### Step 4: Deploy!

Click **Deploy** → Wait 2-3 minutes → Your public link appears!

## Troubleshooting:

If deployment fails:
1. Check `.streamlit/config.toml` exists
2. Ensure `requirements.txt` has all dependencies
3. Try deployment again from Streamlit Cloud dashboard
